# Superstore Sales Analysis Project

## Overview
This project analyzes Superstore sales data using Python+pandas and Tableau.

## Files
- `Superstore_Analysis.ipynb` - Python analysis
- `cleaned_superstore.csv` - Cleaned dataset

## Tools Used
- Python (Pandas)
- Tableau

## Key Findings
- Technology has highest sales
- West region leads in sales
- Consumer segment is largest

## How to Use
1. Run Jupyter notebook to clean and analyze data
2. Import the clean CSV file into Tableau
3. Create visualizations & dashboard for the data
